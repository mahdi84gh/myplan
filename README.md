# 📔 دفترچه برنامه‌ریزی

یک دفترچه برنامه‌ریزی روزانه (تک‌فایل، بدون نیاز به سرور) با تقویم شمسی/میلادی، مدیریت تسک، اهداف بلندمدت، یادداشت‌های ثابت و لیست خرید — که می‌تونی مثل یک اپ روی گوشیت نصب کنی.

## ساختار فایل‌ها

```
index.html                 ← کل برنامه (HTML + CSS + JS)
manifest.json               ← تنظیمات نصب روی گوشی (PWA)
service-worker.js           ← فعال‌سازی کارکرد آفلاین
icons/icon-192.png
icons/icon-512.png
icons/icon-512-maskable.png
icons/apple-touch-icon.png
```

همهٔ داده‌ها (تسک‌ها، یادداشت‌ها، اهداف، تنظیمات) فقط روی خود گوشی/مرورگرت ذخیره می‌شن؛ به هیچ سروری فرستاده نمی‌شن.

---

## مرحلهٔ ۱ — ساخت مخزن (Repository) در گیت‌هاب

1. وارد [github.com](https://github.com) شو و لاگین کن (اگه اکانت نداری، یکی بساز).
2. گوشهٔ بالا-راست روی `+` بزن و **New repository** رو انتخاب کن.
3. یک اسم بذار، مثلاً `planner`.
4. حالت رو روی **Public** بذار (برای این‌که GitHub Pages مجانی کار کنه).
5. روی **Create repository** بزن.

## مرحلهٔ ۲ — آپلود فایل‌ها

1. توی صفحهٔ مخزنی که ساختی، روی **Add file → Upload files** بزن.
2. تمام فایل‌ها و پوشهٔ `icons` رو (با همون ساختار بالا) بکش و بنداز داخل کادر آپلود.
   - نکته: باید پوشهٔ `icons` هم با همین اسم و بدون تغییر آپلود بشه تا آیکون‌ها درست پیدا بشن.
3. پایین صفحه روی **Commit changes** بزن.

## مرحلهٔ ۳ — فعال‌سازی GitHub Pages

1. توی مخزن، برو به تب **Settings**.
2. از منوی سمت چپ **Pages** رو انتخاب کن.
3. زیر «Build and deployment» → «Source» رو روی **Deploy from a branch** بذار.
4. برنچ رو `main` و پوشه رو `/ (root)` انتخاب کن، بعد **Save**.
5. چند ثانیه صبر کن (رفرش کن)؛ یک لینک شبیه این ظاهر می‌شه:

   `https://USERNAME.github.io/planner/`

   این آدرس نهایی برنامه‌ته.

---

## مرحلهٔ ۴ — نصب روی گوشی

### اندروید (کروم)
1. لینک بالا رو توی مرورگر **Chrome** گوشیت باز کن.
2. روی منوی سه‌نقطهٔ بالا-راست بزن.
3. گزینهٔ **Add to Home screen** یا **Install app** رو بزن.
4. تأیید کن — آیکون برنامه روی صفحهٔ اصلی گوشیت میفته و مثل یک اپ مستقل (بدون نوار آدرس مرورگر) باز می‌شه.

### آیفون (سافاری)
1. لینک رو توی **Safari** باز کن (حتماً سافاری، نه کروم).
2. روی آیکون Share (مربع با فلش رو به بالا) بزن.
3. **Add to Home Screen** رو انتخاب کن و تأیید کن.

بعد از نصب، برنامه حتی بدون اینترنت هم باز می‌شه (به لطف service worker) و داده‌هات همون‌جا روی گوشی ذخیره می‌مونن.

---

## به‌روزرسانی بعدی

هر وقت خواستی تغییری بدی، کافیه فایل `index.html` (یا بقیهٔ فایل‌ها) رو دوباره توی گیت‌هاب آپلود/ویرایش کنی (**Add file → Upload files** یا ویرایش مستقیم با آیکون مداد). چند لحظه بعد نسخهٔ آنلاین و نسخهٔ نصب‌شده روی گوشی (بعد از باز و بسته کردن) به‌روز می‌شه.

## جایگزین: با خط فرمان Git

اگه با Git راحتی:

```bash
git init
git add .
git commit -m "planner app"
git branch -M main
git remote add origin https://github.com/USERNAME/planner.git
git push -u origin main
```

بعدش همون مراحل ۳ و ۴ بالا رو انجام بده.
